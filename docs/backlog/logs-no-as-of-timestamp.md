# `xrun logs` не говорит, на какой момент актуален вывод

На Kaggle stdout приходит только по тику поллера (60 с, через MLflow
чанки). `xrun logs <id>` печатает то, что есть в БД, без отметки времени
последнего обновления, и агент не может отличить «ядро молчит» от
«поллер ещё не забрал». Нужна строка `as of <время последнего тика>` в
конце текстового вывода (в `--json` — поле). Источник: отчёт
powerline-seg-v1, 2026-10-09, §6.
