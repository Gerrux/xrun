# Почему первая версия `dales2-powerline-cache-v1` оказалась пустой

Отчёт powerline-seg-v1 (2026-10-09, §1) объясняет пустой датасет режимом
`--dir-mode skip`. Это не подтверждается: `datasets_create` и
`datasets_version` передают `--dir-mode tar` с коммита 6550913, который
входит в установленный 0.10.0. Причина не установлена.

Что проверить на Kaggle в истории версий датасета:
- лежали ли в первой версии `train.tar` / `val.tar` нераспакованными
  (тогда «cache train/ not found» объясняется тем, что tar не каталог);
- был ли «size 0» артефактом отображения сжатого размера в `dataset list`.

Сверка числа файлов после push (добавлена 2026-10-09) поймает оба случая
независимо от причины. Карточку закрыть, когда ответ будет известен;
если виноват tar, менять режим на `zip`.
