# `doctor` проверяет все вендоры с кредами, даже при работе с одним

`active_vendors` объединяет вендоров из кредов и из манифестов. При
настроенном vast и работе с Kaggle в вывод попадает
`WARN vastai_ssh_key`, который к текущему запуску не относится. Это по
дизайну: doctor отвечает за окружение целиком.

Неизвестно, нужен ли флаг `--vendor <name>` (или сужение до вендоров
переданных `--manifest`), или достаточно того, что WARN не влияет на exit
code. Решать, если шум будет мешать агенту ещё раз. Источник: отчёт
powerline-seg-v1, 2026-10-09, §5.
