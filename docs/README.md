# Документация xrun

Обзор продукта — в [README](../README.md) корня; здесь то, что в него не влезло.
Пишется всё это по-русски: русский в проекте исходный язык. Переведён только
README — им продукт и объясняется тому, кто пришёл в первый раз.

| | |
| --- | --- |
| [CLI](CLI.md) | все подкоманды, флаги, машинный вывод, коды выхода |
| [Манифест](MANIFEST.md) | полная YAML-схема с примерами под каждого вендора |
| [Архитектура](ARCHITECTURE.md) | компоненты, поток данных запуска, модель поллера, отказы |
| [События и метрики](EVENTS.md) | протокол `events.jsonl` / `metrics.jsonl` и `xrun_hook` |
| [Состояние](STATE.md) | схема SQLite, миграции, резервная копия |
| [TUI](TUI.md) | экраны, биндинги, темы |
| [Скилл для агентов](SKILL.md) | что скилл делает и чего не делает |
| [Дорожная карта](ROADMAP.md) | история версий и что дальше |
| [Фирменный стиль](brand.md) | знак, палитра, где он нарисован |

Шаблоны манифестов — не здесь, а в [exp/templates](../exp/templates/README.md):
их копируют, а не читают.

Рядом лежит и сайт: `index.html` — это то, что GitHub Pages отдаёт на
[gerrux.github.io/xrun](https://gerrux.github.io/xrun/). Словарь переводов лежит
в самой странице.

Остальное — рабочие записи, а не документация: они описывают, как решение
принималось, и устаревают вместе с решением.

- `notes/` — журнал отказов с живых запусков (`field-issues.md`), хвосты после
  v0.3 (`follow-ups.md`), аудит стабильности (`stability-review.md`);
- `plans/completed/` — планы ранних версий;
- `superpowers/specs` и `superpowers/plans` — замыслы и планы.
