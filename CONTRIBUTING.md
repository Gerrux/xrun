# Как помочь xrun

*English: this file is Russian, like the rest of the docs — Russian is the
project's source language. Issues and pull requests in English are welcome all
the same; someone will answer. The README exists in
[English](README.en.md).*

Помощь нужна разная, и код — не самая дефицитная её часть.

## Что нужно больше всего

**Отчёты с живых вендоров.** У vast.ai, Kaggle и SSH-серверов API ведут себя
каждый по-своему, и тесты с моками этого не ловят. Половина исправлений в
истории пришла из журнала отказов живых запусков
([docs/notes/field-issues.md](docs/notes/field-issues.md)). Отчёт «запустил,
вот что вышло» стоит дороже патча.

**Отчёты об ошибках.** К каждому приложите вывод `xrun doctor --json` — он
проверяет окружение, и половина отказов объясняется им же — и
`xrun events <id> --json` упавшего запуска. Ключей, токенов и адресов своих
серверов туда не вставляйте: `doctor` без `--verbose` их не печатает, но
проверьте глазами.

**Windows и macOS.** Разработка идёт на Windows, CI гоняет все три системы, но
установщики и планировщик (`schtasks`, `crontab`) на живых машинах проверены
не везде.

## Прежде чем писать код

Заведите issue, если правка больше однострочной. Проект держится на одном
обещании, и правка, спорящая с ним, отклоняется не из вредности:

> Инстанс, за который капает счёт, никогда не остаётся без присмотра.

Из него следует то, что чаще всего предлагают и что не принимается: «не
гасить инстанс после ошибки, чтобы посмотреть», если это не явный флаг с
уведомлением; тихий `warn!` вместо push, когда уничтожение не удалось;
поллер, который выходит, не дойдя до терминального статуса.

## Сборка и проверка

Минимум перед PR — то же, что бежит в CI:

```bash
cargo fmt --all -- --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
```

Python-часть:

```bash
pip install -e "python/xrun_hook[dev]" && (cd python/xrun_hook && python -m pytest tests/ -q)
pip install -e python/xrun_tui && (cd python/xrun_tui && python -m pytest tests/ -q)
```

На Linux для `plotters` нужен `libfontconfig1-dev`. TUI требует Python 3.11+,
хук — 3.9+.

Живой прогон без кредов и денег — `xrun launch exp/templates/quickstart.yaml`;
сценарии на отказ, большие метрики и артефакты — в [exp/tests](exp/tests/README.md).
Перед любым изменением поведения манифеста гоняйте `xrun launch --dry-run`.

## Тесты

- Интеграционные тесты лежат в `crates/*/tests/`, юнит-тесты — в
  `#[cfg(test)] mod tests` внутри модуля.
- Тест, который запускает `xrun`, изолируется через `XRUN_CONFIG_DIR` и
  `XRUN_DATA_DIR` во временном каталоге (см. `crates/xrun-cli/tests/agent_contract.rs`)
  и никогда не трогает настоящую БД пользователя.
- Ключи в тестах — фейковые литералы вроде `"test-key-abc"`. Вендорские HTTP —
  через `wiremock`, не через сеть.
- Новое поле JSON-вывода — это контракт для скриптов и агентов: добавлять
  можно, переименовывать и убирать — только с записью в CHANGELOG.

## Пулл-реквесты

- Одна тема на PR. Причёсывание соседнего кода заводите отдельно — так его можно
  принять, не задерживая основную правку.
- Сообщения коммитов — [Conventional Commits](https://www.conventionalcommits.org/)
  по-английски, как вся история: `fix(poller): drain metrics before terminal
  return`, `feat(kaggle): ...`. Тема говорит про последствие, а не про
  действие; загляните в `git log`.
- Комментарии объясняют «почему», а не «что».
- Схема SQLite меняется только новой миграцией
  (`crates/xrun-core/src/store/migrations/NNN_*.sql`), старые не правятся —
  они уже применены у пользователей.
- Каждый `Command` для подпроцесса на Windows получает `CREATE_NO_WINDOW`,
  иначе TUI мигает консолями.
- Пользовательское изменение — строка в `[Unreleased]` в
  [CHANGELOG.md](CHANGELOG.md). Новая команда или флаг — ещё и
  [docs/CLI.md](docs/CLI.md), а если это меняет поведение агента — скилл
  `claude/skill.md`.

## Чего в проект не приносят

Телеметрию и аналитику в любом виде. Наружу `xrun` ходит только к вендорам и
синкам, которые пользователь сам настроил, к каналам уведомлений, которые он сам
включил, и к `api.github.com` за проверкой обновлений (выключается
`XRUN_NO_UPDATE_CHECK=1`).

Креды — только в `credentials.toml` в каталоге конфигурации пользователя.
Ни в манифест, ни в переменные окружения инстанса, ни в логи.

## Безопасность

Утечку кредов или способ оставить инстанс тарифицироваться незаметно не
заводите публичным issue — как сообщить, написано в [SECURITY.md](SECURITY.md).
